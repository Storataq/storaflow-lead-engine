# Email Consent Evidence (Phase 21I)

Table: `email_consent_records`

Stores opt-in / withdrawal / reconfirmation evidence with:

- consent status
- timestamps
- source / collection method
- text/version placeholders
- lawful basis placeholder
- optional hashed IP / UA when enabled

**Important:** The system does not invent legal consent from inferred interest. Campaign Ready ≠ consent.
